# config/

This folder will hold the configuration of each MeshCore device, with secrets removed.

## What will go here

- **`radio.md`**: radio.md will have the radio settings all our devices must share to work together. That includes frequency, bandwith, etc. We will use the Canada / North America preset from the Meshcore web flasher

- **`repeater-1.txt`**: Repeater.txt will have the repeaters settings like the node name, radio settings

- **`companion-1.txt`, `companion-2.txt`**: We will also have companion files that have the setting for each of our companion devices
